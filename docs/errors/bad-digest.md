# 0x80096010 TRUST_E_BAD_DIGEST

**现象**：签名存在，但「哈希不匹配」；常见于下载不完整、被修改、打包后重签失败。

**常见原因**

1. 文件被改动（注入、加壳、二次打包）
2. 下载/复制损坏
3. 签名后又被工具追加/修改了内容

**怎么区分**

- certdiag 分类 `hash_mismatch`，置信度 high
- 报告里 `pe.trailing_after_signature > 0` 表示签名后还有数据（值得注意，但不必然是恶意）

**下一步**

- 与官方哈希对比；重新下载
- 如果是自己发布：确认签名后没有再改文件
