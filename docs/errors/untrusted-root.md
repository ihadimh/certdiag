# 0x800B0109 CERT_E_UNTRUSTEDROOT

**现象**：签名看起来完整，但系统提示「根证书不受信任」；证书链最后一项是自签名或企业根。

**常见原因**

1. 自签名证书（内部工具、测试包）
2. 企业根证书没有部署到目标机器
3. 根证书被手动删除/被策略禁用

**怎么区分**

- certdiag 分类为 `untrusted_root`，`chain.elements` 最后一跳会标 `UntrustedRoot`
- `certutil -verify 文件` 看链尾证书主体

**下一步**

- 企业环境：把根证书部署到「受信任的根证书颁发机构」
- 个人用户：确认来源；不要为了"能跑"盲目信任未知根
