## 实测教训：CSDN 必须用 Markdown 编辑器

2026-11-20 两次发布的对比：

| 方式 | 代码块 | 结果 |
|---|---|---|
| 富文本（粘 HTML/DOCX） | `<pre>` 被净化掉，**11 处代码全部变成普通段落** | 不可用 |
| Markdown 编辑器 | 11 个代码块完整保留，行内代码也保留 | 正确 |

结论：**CSDN 上发布一律用 Markdown 编辑器**，`dist/article-package/文章-CSDN-Markdown.md` 是为此准备的版本：

1. 标题用「」而不是直引号（CSDN 会把直引号转成两个左引号）
2. 图片位置留 `<!-- 在此插入 图 N -->` 注释，图片手动拖进编辑器
3. 粘贴后**删掉正文第一行的 `# 标题`**——CSDN 已把标题放在页头，Markdown 里的 `#`
   会变成正文中的一个二级标题，造成重复

发布后检查清单：

- [ ] 代码块是否还是等宽（Markdown 编辑器下应当正常）
- [ ] 正文第一行是否重复标题
- [ ] 标签是否够 5 个（默认只取 3 个）
- [ ] 摘要是否通顺（不填会自动截取正文）
